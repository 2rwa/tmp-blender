# Fire Column

Lightweight procedural fire experiment intended for fast GitHub Actions iteration.

It avoids a fluid/smoke bake for the first pass and instead uses:

- layered animated emissive flame tongues
- compositor fog glow
- flickering warm point light
- rising emissive sparks
- reflective dark floor and metal burner
- slight camera dolly

The full MP4 and Blender file stay in the Actions artifact. The poster and validation metadata are published under `results/fire-column/`.

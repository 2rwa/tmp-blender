# Water Dump

Short motion experiment for an obvious "water dumping" shot.

The first version avoids an expensive Mantaflow bake and combines:

- animated Ocean modifier surface
- glossy/transmissive water material
- continuous curved pour stream
- staggered falling droplets
- expanding splash droplets
- tilted metallic spout
- slight camera dolly

Full outputs are stored in the Actions artifact; the shared pipeline commits only the poster preview and validation metadata.
